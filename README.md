# 🐍 Python Mini Projects

A collection of beginner-to-intermediate Python mini projects created to practice Python programming, problem-solving, logic building, GUI development, and Object-Oriented Programming.

## 📌 About This Repository

This repository contains small Python projects that demonstrate different Python concepts and practical applications.

The main goal of this repository is to strengthen my Python fundamentals by building projects instead of only learning theory.

## 🚀 Projects

| # | Project | Description | Concepts Used |
|---|---------|-------------|---------------|
| 1 | 🎮 Tic Tac Toe | A simple two-player Tic Tac Toe game | Python, Tkinter, Functions, GUI |
| 2 | 🔢 Calculator | Basic calculator for arithmetic operations | Functions, Conditions |
| 3 | 🔐 Password Generator | Generates secure random passwords | Random, Strings, Functions |
| 4 | 🎯 Number Guessing Game | User tries to guess a randomly generated number | Loops, Conditions, Random |
| 5 | ⏱️ Digital Clock | Displays the current time using a GUI | Tkinter, DateTime |
| 6 | 📝 To-Do List | Simple application to manage tasks | Lists, Functions, Tkinter |
| 7 | 🎲 Dice Roller | Simulates rolling one or multiple dice | Random, Functions |
| 8 | 🪨 Rock Paper Scissors | Classic Rock-Paper-Scissors game | Conditions, Random, Loops |

> More projects will be added as I continue learning Python.

## 🛠️ Technologies Used
